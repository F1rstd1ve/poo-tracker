# LAP-Taste öffnet das Aktionsmenü statt Runden zu zählen

> **Ersetzt durch [ADR 0005](0005-lap-legt-sack-ab-menue-auf-menu-halten.md).**


Während eines Spaziergangs öffnet die BACK/LAP-Taste ein kontextabhängiges Aktionsmenü (oben vorausgewählt: *Sack ablegen*, bzw. *Aufgehoben* / *Entsorgt* je nach Lage), statt eine Runde zu setzen. So bleibt die häufigste Aktion bei zwei Tastendrücken (LAP → START), ohne unzuverlässige Lang-Druck-Erkennung, und alle Mülleimer-Aktionen liegen an einem Ort. Runden gibt es in Gassi-Depot bewusst nicht.
